# Linux for Programmers

This section is a Linux learning series for programmers who want to become confident working in the terminal, managing files, understanding permissions, running processes, using networking commands, and deploying simple applications.

Linux is a core foundation for cloud, DevOps, automation, containers, CI/CD, and production troubleshooting. The goal of this section is to build practical command-line skills step by step, with notes and labs that connect directly to real engineering work.

## What You Will Learn

- How to navigate and work inside the Linux terminal
- How the Linux file system is structured
- How users, groups, permissions, and ownership work
- How to inspect and manage running processes
- How to use common networking and environment commands
- How to work with text editors and shell scripts
- How to deploy a simple Python web server on Linux
- How to use powerful Linux commands for day-to-day engineering tasks

## Learning Goal

By the end of this section, you should be comfortable using Linux as a programmer and as a future cloud or DevOps engineer. You should be able to move around the system, inspect files and processes, understand permissions, write basic scripts, and troubleshoot common command-line issues with confidence.
